### 🎯 최우선 작업: 데이터 파이프라인 재가동
**목표:** YouTube Data API 연동 실패 문제를 해결하고, 채널의 현재 성과(KPI) 및 경쟁 환경 데이터를 확보하여 모든 후속 작업을 위한 기초 체력을 만듭니다.

**실행 방안 (사전 조치 필요):**
이 작업은 에이전트 분배가 아니라, 사장님께서 시스템 설정을 통해 API 키와 채널 ID를 재입력하는 **시스템 환경 설정**이 가장 먼저 필요합니다.

1.  **API 인증 복구:** 가장 시급한 문제입니다. API 키와 채널 ID가 없으면 `trend_sniper`, `comment_harvester`, `my_videos_check` 등 모든 도구가 작동할 수 없습니다.
2.  **데이터 수집 순서:**
    *   **1단계 (Setup):** `youtube_account`를 통해 API 키와 채널 ID를 입력합니다.
    *   **2단계 (Analysis):** `channel_full_analysis`를 실행하여 채널의 현재 상태를 깊이 있게 진단합니다.
    *   **3단계 (Input Gathering):** `comment_harvester`를 실행하여 시청자가 실제로 쓰는 '후크 단어'를 메모리에 누적시킵니다.

이 단계가 완료되어야만, 제가 목표했던 '후크 강한 영상 기획서 3개 작성'과 '감시 채널 댓글 패턴에서 후크 단어 5개 추출'이 실질적으로 가능해집니다.

---
**⚠️ 중요 알림: 데이터 부족으로 모든 고급 분석이 차단되었습니다.**

현재 시스템 로그를 보면, API 키와 채널 ID가 누락되어 데이터 수집 자체가 실패하고 있습니다. 이 부분이 해결되지 않으면 어떤 에이전트도 아무것도 할 수 없습니다.
